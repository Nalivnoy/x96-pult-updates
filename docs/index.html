FIRST TIME

Install without a USB drive

  1. Download on the TV box.

    Choose Download APK above, then open the file from the browser's Downloads or a file manager.

  2. Confirm installation.

    If Android asks, allow that browser or file manager to install apps. Install and open X96 Пульт.

  3. Set up control.

    Open Настройка (Setup) in the TV app. Enable the debugging access your firmware requires, then choose Запустить (Start).

  4. Connect your browser.

    From a phone, tablet or computer in the same home network, scan the TV's QR code or enter its local address, then enter the pairing code.

ALREADY INSTALLED

Update from the TV

  1. Open Обновления (Updates).

    The TV app shows when a new version is available. Choose Скачать обновление (Download update).

  2. Allow installation if requested.

    Choose Разрешить установку (Allow installation), enable the permission for X96 Пульт and return to the app.

  3. Install the update.

    Choose Установить обновление (Install update) and confirm the Android installer.

No Updates button yet?

Download the APK above and install it over the existing app once. Keep the old app installed to preserve your pairing code and settings.

Before you start

Tested on X96Q with slimBOXtv ATV 10.11 / Android 10. Android 8+ is required; other firmware may need additional setup. On the tested firmware, USB debugging enables the ADB TCP port 5555. Modern wireless debugging pairing is not supported yet.

Use a trusted home network. Allow local network access in your VPN if necessary. The home remote works locally; downloads, updates and optional remote assistance require internet.

If you download on a phone or computer, transfer the APK to the TV box before opening it there. Installing on one device does not install on another. The QR code in the TV app opens your local remote.

Full English instructions ↗

Help family over the internet

On the TV: Удалённая помощь (Remote assistance) → Создать сеанс (Create session). Tell your helper the 16-character code, then confirm their name on the TV. Screen and control stay unavailable until you approve.

The screen uses periodically refreshed images. Either side can end the session; access expires after 30 minutes.

ПЕРВАЯ УСТАНОВКА

Без флешки

  1. Скачай файл на приставку.

    Нажми «Скачать APK» выше. Открой файл из «Загрузок» браузера или через файловый менеджер.

  2. Подтверди установку.

    Если Android попросит, разреши установку этому браузеру или файловому менеджеру. Установи и открой «X96 Пульт».

  3. Включи управление.

    Кнопка «Настройка» объяснит, какой доступ отладки нужен на твоей прошивке. После настройки нажми «Запустить».

  4. Открой пульт в браузере.

    На телефоне, планшете или компьютере в той же домашней сети отсканируй QR с телевизора или введи его локальный адрес. Введи код привязки с телевизора.

УЖЕ УСТАНОВЛЕН

Обновляй с телевизора

  1. Открой «Обновления».

    Приложение на телевизоре покажет, есть ли новая версия. Нажми «Скачать обновление».

  2. Разреши установку, если нужно.

    Нажми «Разрешить установку», включи разрешение для «X96 Пульта» и вернись в приложение.

  3. Установи новую версию.

    Нажми «Установить обновление» и подтверди установку Android.

Кнопки «Обновления» ещё нет?

Один раз скачай APK сверху и установи поверх прежней версии. Не удаляй приложение — тогда код и настройки сохранятся.

Перед установкой

Проверено на X96Q со slimBOXtv ATV 10.11 / Android 10. Нужен Android 8+; другие прошивки могут требовать отдельной настройки. На проверенной прошивке USB-отладка включает ADB TCP на порту 5555. Современное сопряжение беспроводной отладки пока не поддерживается.

Используй доверенную домашнюю сеть. При необходимости разреши локальную сеть в VPN. Домашний пульт работает локально. Для скачивания, обновлений и удалённой помощи нужен интернет. С версии 1.6.0 можно создать сеанс помощи и разрешить близкому человеку экран и управление на срок до 30 минут.

При скачивании на телефон или компьютер передай APK на приставку и открой его там. Установка на одном устройстве не устанавливает приложение на другое. QR-код в приложении на телевизоре открывает твой локальный пульт.

Помощь близким через интернет

На телевизоре: «Удалённая помощь» → «Создать сеанс». Назови помощнику код из 16 символов и подтверди его имя на телевизоре. Без подтверждения экран и управление недоступны.

Экран передаётся обновляемыми снимками. Завершить помощь можно с любой стороны; сеанс ограничен 30 минутами.
