# X96 Пульт — обновления

Управление Android-приставкой из браузера телефона, планшета или компьютера.
Пульт работает в домашней сети. Для проверки и скачивания обновлений нужен интернет.

## Скачать и установить

Откройте [последний выпуск](https://github.com/Nalivnoy/x96-pult-updates/releases/latest)
в браузере самой приставки и скачайте файл `X96-Pult-<версия>.apk`.
Запустите скачанный APK и подтвердите установку Android.
При необходимости разрешите установку этому браузеру или файловому менеджеру.
При обновлении ставьте поверх прежней версии: удалять приложение не нужно.

В ZIP выпуска есть подробная инструкция и лицензии. На телефоне, планшете и ПК
приложение устанавливать не требуется: откройте адрес или QR с телевизора.

## Следующие обновления

Начиная с версии 1.5.0 откройте приложение на телевизоре → **Обновления**.
Нажмите **Скачать обновление**, дождитесь проверки файла, затем **Установить обновление**.
В первый раз нажмите **Разрешить установку**, включите разрешение для X96 Пульта,
вернитесь назад и нажмите установку. Подтвердите обновление в системном окне Android.

Проверка новых версий выполняется и при открытии приложения (с паузой 6 часов).
Скачивание и установка начинаются по кнопке. Настройки и привязки сохраняются.
Старую версию без этой кнопки нужно один раз обновить вручную по ссылке выше.

## Совместимость

Android 8.0 и новее. Проверено на X96Q со slimBOXtv ATV 10.11 / Android 10.
Для управления на этой прошивке требуется USB-отладка, открывающая ADB TCP/5555.
На других прошивках может понадобиться отдельная настройка сетевого ADB;
современное сопряжение беспроводной отладки пока не поддерживается.
Для курсора необходима поддержка UHID. Используйте доверенную домашнюю сеть.

При VPN разрешите локальную сеть или исключите X96 Пульт из VPN.
Коды привязки генерируются отдельно на каждой приставке.

## Содержимое репозитория

Здесь размещены готовые APK, архивы с инструкцией и лицензиями и `update.json`.
Подпись APK, размер, SHA256 и версия проверяются приложением до установки.
Ключи сборки, пользовательские настройки и исходный проект сюда не загружаются.

Сторонние компоненты: scrcpy 5.0.1 и ZXing Core 3.5.4 (Apache License 2.0).
Лицензии включены в APK и установочный архив.
